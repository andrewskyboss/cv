## 📌 Project Overview

This repository contains the source code for my online curriculum vitae. Built with a focus on performance, accessibility, and modern UI/UX practices, it provides a clean, accessible breakdown of my technical background, software development experience, and design portfolio.

### Key Features
* 📱 **Mobile-First Responsive Design:** Adapts smoothly across all screen sizes and mobile devices.
* ⚡ **High Performance:** Lightweight static architecture ensures fast page loads and quick rendering.
* 🎯 **Structured Experience Timeline:** Highlights key roles, technical accomplishments, and design milestones.
* 🔍 **SEO & Search Optimization:** Built-in JSON-LD structured data and Open Graph tags for optimal discoverability on web and AI search platforms.

## 🛠️ Built With

* **Markup & Structure:** HTML5 (Semantic Tags)
* **Styling & Layout:** CSS3, Modern Flexbox/Grid, Bootstrap
* **Interactivity:** Modern JavaScript (ES6+)
* **Icons & Assets:** Font Awesome
* **Hosting Platform:** GitHub Pages
